# SMSD benchmark reports

The [7.2.0 report](RESULTS_7.2.0.md) records measured versions, matching rules,
search budgets and result checks. The [benchmark guide](README.md) describes
running the tools; the [data guide](data/README.md) records corpus sources.

Earlier `results_*` files are historical outputs with different chemistry rules
or setup costs. Use each report's stated scope when comparing results.
