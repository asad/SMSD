    SMSD Pro 8.1.0 API reference¶

    This reference describes the 8.1.0 source API. Use a matching wheel or build; an earlier installed native extension cannot provide new Python APIs.

    The Python package provides molecular graphs, exact searches, fingerprints, screening, depiction and optional data adapters. Java and C++ expose related graph operations; their names and available options are documented in the Java guide and C++ guide. Identical fingerprint parameters do not establish bit identity across toolkits.

    MCS and substructure searches¶

    import smsd

options = smsd.MCS.Options()
options.timeout_ms = 1000
options.node_limit = 100000
result = smsd.MCS.find("CCO").with_options(options).match("CCN")
assert result.found and result.best.atom_count == 2
assert smsd.MCS.validate_mapping("CCO", "CCN", result.best, options) == []

    MCS.Objective.MCIS maximises common atoms while preserving edges and non-edges. MCES maximises selected common bonds; its witness includes the chosen bonds as well as atoms. The objectives are different and should not be compared as interchangeable scores. MCS.Connectivity.CONNECTED requires a connected common graph; FRAGMENTS permits disconnected selected components. with_fragments(min_atoms=..., max_fragments=...) selects the latter mode. with_atom_weights assigns weights to query atoms in MCIS; weighted scores are not atom counts. Use the matching options when validating a witness.

    Prepared searches copy options and support match, match_all(limit=...) and match_many(num_threads=...). A prepared query can be reused; avoid mutating its source molecule or shared mutable inputs during calls. Options are copied, but a shared cancellation token intentionally remains a signal to all searches using it. num_threads=0 selects the native OpenMP default; set an explicit positive thread count for a controlled batch.

    SearchResult contains matches, status, optimal, complete, score, nodes_visited and elapsed_ms; found and best are convenience properties. best is None when there is no witness. Match contains atom_mapping, selected bond_mapping and fragments, with atom_count and bond_count. For SMILES inputs, atom indices are zero-based in parsing order. Foreign molecule inputs retain their caller-visible numbering through conversion.

    Inspect found, status, optimal and complete separately. A time-, node- or cancellation-stopped call can retain a useful witness without proving an optimum. An unfinished result with no witness does not prove absence. complete also records enumeration completeness; a requested result limit can stop enumeration after an optimum is found. Ring-perception work limits can prevent a proof even when a mapping is feasible. Preserve stopped cases when analysing outcomes; stopped latency is not completed-work throughput.

    Search budgets apply after input parsing and preparation. General API options permit native defaults and unlimited node settings; set explicit finite limits when accepting untrusted or interactive requests. The MCP tools impose their own stricter limits. timeout_ms=0 requests an immediate timeout. A CancellationToken is one-way: call cancel() and create a fresh token for a later independent request.

    ChemOptions controls atom type, charge, isotope, bond order, aromatic compatibility, stereo, ring and optional tautomer handling. The default profile does not require matching formal charges or isotopes. Use explicit options or ChemOptions.profile("strict") when those restrictions matter; do not infer them from a tool or method name. complete_rings_only, ring_matches_ring_only and ring_fusion_mode impose different restrictions. The graph aromaticity model is a preparation choice, selected through perceive_aromaticity or the builder. The deprecated chemistry aromaticity_model field is not read by search.

    query = smsd.Substructure.smarts("[OX2H]")
assert query.match("CCO").found
assert not query.match("CCN").found

embeddings = smsd.Substructure.smarts("[#8]").match_all("OCCO", limit=8)
assert len(embeddings.matches) == 2

    Substructure.find takes a molecule query; Substructure.smarts compiles a predicate query. with_induced(True) additionally requires query non-bonds to remain non-bonds. SMARTS predicates can specify hydrogen, isotope, charge, aromaticity and topology directly. A parsed SMARTS string and a proved search result are separate facts.

    MCS.match_constrained processes queries in order while excluding already used target atoms. MCS.consensus builds a progressive common graph with a support threshold and supporting mappings. It is an approximation and always reports optimal=False, including empty and single-input calls. complete reports whether the progressive pass finished. Neither it nor COMPLETED proves a global multi-molecule optimum or absence of a qualifying common graph. is_mapping_maximal tests extendibility of a given valid mapping, which is different from proving a maximum. Symmetry canonicalisation and tautomer-confidence helpers also have separate contracts; confidence is a heuristic, not a search proof or stability prediction.

    Result graphs, SMARTS and images¶

    Match.to_graph(query) and Match.to_smiles(query) extract selected atoms and bonds. A partial selected graph can have capped valences and should not be mistaken for an unchanged fragment of the original complete molecule. Match.to_smarts(query, chemistry) and MCS.match_with_smarts(target) export portable predicates for represented selected graphs. Unsupported stereo, tautomer and ring-export constraints raise rather than being silently dropped. A SMARTS predicate does not carry an optimum proof, enumeration status or all induced non-edge requirements; retain the associated SearchResult.

    exported = smsd.MCS.find("CCO").match_with_smarts("CCN")
assert exported.result.found
assert smsd.Substructure.smarts(exported.smarts).match("CCN").found

from smsd.highlight import mcs_svg
svg = mcs_svg("CCO", "CCN", exported.result)
assert '<svg' in svg and 'data-search-status=' in svg

    Native depict_svg, depict_mapping and depict_pair return SVG strings and use DepictOptions. The pair renderer highlights mapped atoms and input bonds between them. smsd.highlight.mcs_svg carries search flags in the SVG and rejects selected-edge witnesses that this renderer would over-highlight; render best.to_graph(query) separately in that case. The MCP depiction tool instead labels this highlighting scope and returns the selected bond mapping alongside the image.

    The older depict_mcs, depict_substructure and deprecated to_svg helpers use the optional RDKit drawing dependency. Their convenience images do not replace the proof-bearing result. The native SVG functions need no external drawing toolkit. save_svg writes only when explicitly called.

    Molecule I/O and chemistry¶

    parse_smiles accepts OpenSMILES text; an empty string constructs an empty graph. lenient=True explicitly requests recovery from malformed input. to_smiles writes the native canonical representation, including supported stereo and atom maps. Canonical ordering can differ between language ports. canonical_hash and graph canonical hashes are compact screening keys, not proofs of molecular identity or difference. same_canonical_graph compares native canonical outputs; use a validated mapping when exact identity is required by an application.

    read_mol_block, read_mol_file, write_mol_block, write_mol_block_v3000 and write_molfile cover MOL V2000/V3000 text or files. read_sdf, write_sdf and write_sdf_record cover SDF records. read_sdf loads the whole file and represents malformed records as empty graphs; inspect them rather than counting every record as accepted chemistry.

    from pathlib import Path
from tempfile import TemporaryDirectory

with TemporaryDirectory() as directory:
    destination = Path(directory) / "molecules.sdf"
    smsd.write_sdf(["CCO", "CCN"], destination)
    assert [graph.n for graph in smsd.read_sdf(destination)] == [3, 3]

    MolGraphBuilder takes explicit atom properties, adjacency and parallel bond properties. Its build can run aromaticity perception; select that behaviour deliberately when carrying an externally prepared representation. MolGraph exposes atom and bond properties and lazy invariant getters. prewarm prepares common invariants; perceive_aromaticity and kekulize explicitly change a graph. Do not mutate it concurrently with reads/searches. Molecule names, comments, program lines and SDF properties are ordinary metadata.

    compute_sssr, rings_truncated, relevant_cycles_truncated and graph ring-system methods expose ring perception. rings_truncated keeps its 8.0.x meaning: the ring search behind compute_sssr stopped before finding a complete set of rings. That search works within one fixed, deterministic work limit; see Results and budgets. relevant_cycles_truncated separately reports incomplete relevant-cycle enumeration. Strict ring fusion compares per-atom ring counts; complete-ring matching uses relevant cycles. Each checks completeness of the perception it uses. assign_cip, assign_rs and assign_ez expose represented stereo descriptors, including unresolved cases; missing annotations are not inferred experimental configurations. count_components, split_components, extract_subgraph and murcko_scaffold return graph topology or transformed graph objects, rather than implicitly standardising every input.

    compute_relevant_cycle_families groups the relevant cycles into families, each with one member and its exact number of members as a Python integer, so they can be counted without listing them; truncated reports an incomplete enumeration. relevant_cycle_family_of finds the family of a ring and relevant_cycle_family_members lists members up to a limit. When the enumeration is complete, the relevant cycles and their number do not depend on the input atom order; the grouping into families can.

    from_rdkit/to_rdkit and from_openbabel/to_openbabel use optional toolkit bindings. They pass through molecular text and are not unrestricted object serialisation. get_index_map and translate_mapping preserve RDKit atom numbering. Cache clearing releases reusable conversions without invalidating index maps retained by live graphs. translate_to_atom_ids uses explicitly supplied external graph atom IDs. Keep toolkit versions and conversion choices with cross-tool results.

    Fingerprints and coefficients¶

    fingerprint and fingerprints accept molecules or SMILES and return sorted set-bit positions, or non-zero (position, count) pairs when counts are requested. fingerprint_from_smiles is a text convenience helper. Families include MCS-aware paths, element paths, ECFP/circular, FCFP and topological torsions; FingerprintOptions adds configurable invariants, fragment/scaffold choices, stereo and SMARTS keys. FingerprintOptions.maccs() supplies 166 MACCS keys, with key number k at position k - 1. Fingerprint family names and options are not guarantees of cross-tool bit identity.

    specification = smsd.FingerprintOptions.ecfp(radius=2, size=2048)
first, second = smsd.fingerprints(["CCO", "CCN"], options=specification, num_threads=1)
assert 0 <= smsd.tanimoto_coefficient(first, second) <= 1

counted = smsd.FingerprintOptions(family="ecfp", size=128, counts=True)
counts = smsd.fingerprint("CCCCCC", options=counted)
assert any(count > 1 for position, count in counts)

    Bit Tanimoto is intersection over union; bit Dice and cosine use bit counts. Count Tanimoto uses sum(min)/sum(max), count Dice uses 2*sum(min)/(sum(a)+sum(b)), and count cosine uses the dot product and L2 norms. These are different definitions. Use the count-specific helpers when retaining multiplicity. Empty-input conventions are documented on individual functions. Pass the actual fingerprint width to bit Dice/cosine/distance helpers whose default is 2,048 bits. to_hex, from_hex, to_binary_string and counts_to_array provide explicit serialisation forms. Fingerprint quality estimates concern hashed-vector density/collisions, not biological accuracy.

    batch_similarity ranks by ECFP Tanimoto with stable input-order ties. similarity_upper_bound, its similarity alias and screen_targets are graph-label bounds used for screening; they are neither the same coefficient nor an exact MCS search. TargetCorpus captures molecules once for repeated graph-bound or ECFP screens and exact prepared-query batches.

    Corpus search decisions¶

    Substructure.match_corpus(corpus, *, gpu_prefilter=False, num_threads=0) decides for each target whether it contains the query, and MCS.match_corpus(corpus, minimum_atoms, *, gpu_prefilter=False, num_threads=0) whether its unweighted MCIS with the query has at least minimum_atoms atoms. A conservative pre-screen rules out targets that cannot qualify; the CPU searches the rest, including targets whose bound equals the threshold. Existing match_many is unchanged.

    Each CorpusSearchResult has target_index, atom_upper_bound (integer or None), proven_below_threshold, threshold_reached and result (the actual SearchResult, or None for a target ruled out by the pre-screen). Both decision flags false means unknown; a search stopped below the threshold proves nothing. Substructure has no atom bound. MCES and weighted searches return CPU results, but their scores never prove that a target falls below the atom threshold.

    gpu_prefilter=False runs the pre-screen on the CPU. True asks the optional GPU provider to run it and falls back to the CPU when the device cannot. The GPU is never selected automatically, and graph matching always runs on the CPU. With unsupported query options, node caps, immediate timeouts or cancellation tokens, every target is searched. Original target order and atom numbering are retained. See the Python examples and budget scope.

    Packed corpora, clustering and optional data adapters¶

    FingerprintCorpus is a read-only memory-mapped packed-bit file with explicit fingerprint width and row count. create/from_smiles construct it; fingerprint, iter_packed_chunks, screen_many, similarities, threshold_pairs and top_k_pairs read it. Use its context manager or close. The underlying file must remain unchanged while open. Chunk bounds limit working arrays, not returned-hit storage, mapped pages or total comparison work. Counts of representable rows are not throughput or memory measurements.

    stream_screen_smiles and stream_screen_many_smiles process target iterables in chunks. butina clusters by similarity to a chosen centre; members need not be mutually close. maxmin makes a greedy diverse selection with deterministic input-index ties. Full threshold pair/clustering work can be quadratic even when it avoids a dense distance matrix.

    The smsd.adapters module imports optional dependencies only when requested:

    API Output and dependency
    to_numpy, fingerprints_numpy Dense binary/count arrays; NumPy.
    to_scipy, fingerprints_scipy Sparse matrices; SciPy and NumPy.
    molecules_pandas, molecules_polars Molecule/fingerprint columns; pandas or Polars.
    to_arrow Fixed-size-list fingerprint table; PyArrow and NumPy.
    to_torch, fingerprints_torch Tensors; PyTorch and NumPy.
    to_pyg Molecular graph Data; PyTorch Geometric and PyTorch.
    FingerprintTransformer, SimilarityTransformer Fit/transform estimators for scikit-learn pipelines.

    Arrow can share a native-endian, C-contiguous 2-D integer NumPy buffer and retains its owner. Shared input must not be mutated. Other inputs/layouts can require copies; zero_copy_only=True rejects those cases and table metadata records the ownership/copy result. A tensor/graph adapter's device argument does not itself establish a GPU chemistry kernel.

    Accelerators and molecular tools¶

    Exact MCS/substructure proof remains on the CPU. GPU support is operation-, build-, device- and package-dependent; availability alone does not prove a particular call dispatched to a device. gpu_is_available and gpu_device_info describe discovery. warm_start explicitly prepares a reusable corpus/query path. Packed corpus APIs expose explicit backends and retain deterministic CPU-defined score/hit semantics. Native Metal packed fingerprint screening is available only in C++ and runs only when requested explicitly; Python screening and search never run on Metal. See CUDA operation scope, native Metal scope and the optional smsd-cuda package for build and device requirements; the supported-platforms table lists the GPU that automatic screening uses by default.

    The eight MCP tools expose finite text, atom, target, result and search limits plus status/proof/timing metadata. Native default standardisation changes representation only; opt-in chemical transformations record their optional backend. The tool registry also exports local function definitions in the input-schema, function and chat-function formats, and LangChain and LlamaIndex tools, without creating a model client.

    Compatibility names¶

    The 8.x API retains deprecated names such as canonical_smiles, prewarm_graph, read_molfile, export_sdf, dearomatize, overlapCoefficient, count_overlapCoefficient, to_svg and chem=. Use their documented replacements. Retaining these names is not permission to remove or reinterpret them in a minor release; warnings and old return values remain part of the compatibility behaviour.

    smsd.RingBasisUnavailable is the native RuntimeError subclass raised when a result needs the minimum cycle basis and ring perception reached its work limit before completing it; batch calls add the zero-based input index.
