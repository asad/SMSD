    SMSD search algorithms¶

    The C++, Java and Python libraries share one search model: a prepared query owns a copy of its graph, chemistry and resource options, and each match, matchAll or matchMany call runs an independent search against one target. The Python package calls the native search. The Python, C++ and Java guides document the API; this page states what each search guarantees, what a result means and how the languages differ. The supported-platforms table lists the release packages. Matching runs on the CPU; optional CUDA screening does not perform the MCS search.

    What each search guarantees¶

    • Substructure finds embeddings of the whole query in the target. Non-induced matching requires every query bond in the target; induced matching also forbids extra target bonds between mapped atoms. Enumeration returns every embedding up to the requested limit, symmetric self-mappings included.
    • MCIS (maximum common induced subgraph) maximises mapped atoms, then bonds, or the supplied query atom weights, and preserves both edges and non-edges between mapped atoms.
    • MCES (maximum common edge subgraph) maximises common bonds, then the atoms they touch.
    • Every reported mapping satisfies the chemistry options, and connectivity and fragment limits apply to the reported components.
    • Canonical mapping selection returns one representative mapping under the symmetries of both molecules, or raises an error when it cannot.

    Results and budgets¶

    • Every search reports status, optimal and complete separately from its matches. Completed means the search ran to its end. TimedOut and Cancelled mean the time limit or a cancellation stopped it. LimitReached means the node limit stopped it, an enumeration reached its match limit, or an MCES pair beyond the size limits below was declined before any search; a declined pair returns no match and proves nothing.
    • Complete-ring matching uses full relevant-cycle perception. Strict ring fusion compares per-atom ring counts. If the perception required by either option is incomplete in either input, MCS retains its selected mappings but reports LimitReached, with optimal and complete both false. TimedOut and Cancelled take precedence. Consensus applies the same status rule when any input has truncated ring perception, keeping its fragment and supporting mappings. A valid mapping's maximality cannot be proved in this case, so the check raises its existing proof-unavailable exception.
    • Positive numeric SMARTS R<n> (n > 0) uses one deterministic minimum cycle basis, the same in C++ and Java. When a molecule has more than one minimum cycle basis, R<n> and per-atom ring counts can depend on the input atom order. If ring perception cannot complete the basis, a search that cannot be decided without it returns LimitReached without matches, including for negated, combined and recursive predicates; the empty result does not prove absence. Literal R and R0 remain independent of that basis. Other functions that need the basis raise an error naming the cause; computeSSSR and computeRings may return incomplete rings with truncation flags. relevantCyclesTruncated alone does not make the basis incomplete.
    • Ring perception works within one fixed, deterministic work limit, the same in C++, Java and Python and independent of time, thread count and hardware. Very large fused-ring systems, such as synthetic cages, can reach it. When it is reached, ringsTruncated reports it. A refusal it causes recurs on every run, so a longer timeout will not help. Values computed without the missing ring information are still returned exactly; searches that need it report LimitReached, and other ring-dependent results raise RingBasisUnavailable (Java RingBasisUnavailableException) naming the cause, with the zero-based input index in C++ and Python batch calls.
    • Progressive consensus is an approximation. Its optimal flag is always false, including empty and single-input calls. complete records whether the progressive pass finished. Neither it nor Completed proves a global optimum or absence of a qualifying common graph. Its threshold, budget, selected fragment and supporting mappings retain their existing meanings.
    • A stopped search may return a valid mapping without proving the optimum, and a capped enumeration may prove the objective while leaving the enumeration incomplete. An empty incomplete result does not prove absence.
    • A negative timeout selects the default budget: 10 s for a substructure search and, for an MCS, 500 ms plus 2 ms per atom pair (query atoms × target atoms), at most 30 s. That is 1.3 s for two 20-atom molecules, 5.5 s for two 50-atom molecules and 30 s from 122 atoms each. Zero stops immediately, and a node limit of zero leaves the node count unlimited.
    • Batch results do not depend on the thread count unless a search reaches its time limit.

    Size limits¶

    An MCES search declines a pair, with LimitReached and no match, when query atoms × target atoms exceed 2³⁰, as for two molecules of more than 32,768 atoms each; when the two molecules are too large in bonds, as for two molecules of more than 16,384 bonds each; or, rarely, when a molecule has an atom with 512 or more bonds and the two molecules share many kinds of bond. MCIS searches are never declined. The three libraries share these limits.

    Stereochemistry¶

    With chirality or double-bond stereochemistry enabled, a mapped centre or double bond is compared by the parity of its mapped neighbours, not by CIP labels, whose priorities depend on atoms outside the mapping. The comparison is a hard constraint. MCIS returns the largest common subgraph whose mapped stereochemistry agrees, which can be smaller than the MCIS without it: for the alanine enantiomers N[C@@H](C)C(=O)O and N[C@H](C)C(=O)O it keeps five of the six atoms. MCES instead leaves out the fewest common bonds that resolve each disagreement: for C[C@@H]1CCCO1 and C[C@H]1CCCO1 it keeps all six atoms and five of the six bonds, where MCIS keeps five atoms.
