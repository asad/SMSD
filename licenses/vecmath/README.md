# vecmath

The SMSD Pro™ command-line tool bundles vecmath 1.5.2 (`javax.vecmath:vecmath`),
which the CDK structure diagram generator uses, unmodified. vecmath is
Copyright (c) 1996-2008 Sun Microsystems, Inc. and is licensed under the GNU
General Public License, version 2, with the Classpath exception; the licence
text is in [LICENSE](LICENSE).

## Where vecmath is bundled

- The Java CLI JAR with dependencies contains the vecmath classes, and the
  Java CLI installers built from it carry them, as do the CPU Docker images.
- The portable CLI archive carries the unmodified vecmath JAR.

## Source

The source of vecmath 1.5.2 is published on Maven Central as
`javax.vecmath:vecmath:1.5.2` (`vecmath-1.5.2-sources.jar`).
